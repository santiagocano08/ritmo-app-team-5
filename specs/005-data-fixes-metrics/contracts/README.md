## Compatibility summary

- `gold.service_metric`: same columns and types; consumers keep working but read different numbers and many more
  `computable = false` rows in the first minutes of a run.
- `corridor_now` / `decision_inputs` / `source_status`: same schemas; `headway_ahead_s` of a bus leaving the terminal
  changes from 1,240 s to 615 s (C1 seed 42, 22:20:40Z), and an unplaceable or untrusted bus is `estimated` and
  listed in `sources_down`.
- Snapshot ids change (the rules version is part of the hash).
